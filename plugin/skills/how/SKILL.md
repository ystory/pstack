# How

Explore the codebase to answer "how does X work?" questions.

If the scope is ambiguous, state your interpretation and explore. The user can redirect.

## 1. Explain

Read [Host execution](../poteto-mode/references/execution.md) before delegation. Spawn one subagent that explores and explains in one pass, using the binding's `read-only` worker kind where available, otherwise its `general-purpose` kind, on the actual native parent selection. Include a no-edits instruction in its brief. Give it the user's question and this brief:

> You are writing an architectural explanation for a senior engineer. Explore the codebase and write an explanation that a senior engineer unfamiliar with this area could read and walk away with a solid mental model. They should understand the architecture well enough to start working in it confidently. You have read-only access to the codebase.

## 2. Present

Present the subagent's output. Light edits for clarity or context from the conversation are fine. Do not substantially rewrite it.
